## 1. 개요 및 목표

### 배경
- V4 Active 전략은 4시간봉(4h) 기반으로 높은 백테스트 수익률을 기록했으나, 4시간 단위의 신호 지연으로 인해 급락/급등 상황에서의 대응 속도가 느린 문제가 있었음.
- WebUI를 통한 실시간 모니터링 중 차트 타임프레임 불일치(config: 1h vs 전략: 4h) 문제가 발견됨.

### 목표
- 진입 신호의 **품질은 4h 추세 기준으로 유지**하되, **청산 반응 속도를 1h 단위로 개선**
- Freqtrade 표준 방식(`merge_informative_pair`)을 준수하는 아키텍처 설계

## 2. 핵심 기술 논의

### 2.1 Informative Timeframe 개념

| 구분 | 설명 |
| :--- | :--- |
| **자동 스탑로스** | 5초마다 현재 가격 체크 → -8% 시 즉시 청산 (이미 작동 중) |
| **Informative TF** | 진입/청산 **신호 자체**를 더 정밀하게 만드는 보조 데이터 |

> **핵심**: 자동 스탑로스는 "사후 방어", Informative TF는 "사전 예측 탈출"

### 2.2 Freqtrade 기술 제약 사항 발견

```
❌ 불가: 4h 메인 + 1h informative (merge 방향 오류)
  → "Tried to merge a faster timeframe to a slower timeframe"

✅ 가능: 1h 메인 + 4h informative (Freqtrade 표준 방향)
  → merge_informative_pair(df_1h, df_4h, '1h', '4h')
```

이 제약을 바탕으로 **구조를 역방향으로 설계**: `1h 메인 + 4h 진입 필터`

### 2.3 5분봉(5m) 제외 결정

백테스트 결과 5m 단독 전략:
- **승률 31.3%** / MDD **93.17%** → 노이즈 과다로 사용 불가
- 결론: 5m은 급락 방어에 이론적으로 유효하나, 단독 또는 주 청산 신호로 사용 시 오청산 빈도가 과도함

## 4. V5 전략 아키텍처

### 4.1 구조 다이어그램

```
[데이터 레이어]
  4h 캔들 데이터 (Informative)
    └── EMA200, EMA50, RSI, ADX
    └── bull_trend_4h / bear_trend_4h 생성
         ↓ merge_informative_pair (1h ← 4h)
  1h 캔들 데이터 (메인)
    └── EMA8, EMA21, EMA200, RSI, ADX, TEMA, MACD
    └── FreqAI 예측 (&-target_roi)

[진입 신호 레이어]
  Long Entry = 1h AI 예측 상승
              + 1h EMA 정배열
              + 1h RSI > 50
              + ✅ 4h 상승 추세 필터 (bull_trend_4h == 1)

  Short Entry = 1h AI 예측 하락
               + 1h EMA 역배열
               + 1h RSI < 50
               + ✅ 4h 하락 추세 필터 (bear_trend_4h == 1)

[청산 레이어]
  일반 청산: 1h EMA8 < EMA21 (역전 시 즉시 청산)
  계층적 스탑로스:
    수익 +5% 이상 → -1% (본전 보호)
    수익 +3% 이상 → -3% (타이트 스탑)
    그 외         → -8% (기본 안전망)
  최후 방어: stoploss -8% (5초마다 가격 체크)
```

### 4.2 핵심 파라미터

| 파라미터 | 값 | 설명 |
| :--- | :--- | :--- |
| `timeframe` | `1h` | 메인 캔들 (청산 반응 기준) |
| `informative` | `4h` | 진입 방향 필터 (추세 확인) |
| `stoploss` | `-0.08` | 기본 손절 -8% |
| `trailing_stop_positive` | `0.02` | 수익 +2% 이상 트레일링 활성화 |
| `trailing_stop_positive_offset` | `0.05` | +5% 도달 후 트레일링 추적 |
| `leverage` | `5.0` | 5배 레버리지 |
| `prediction_threshold` | `0.012` | AI 예측 최소 임계값 (1.2%) |
| `adx_min` | `20` | 최소 추세 강도 필터 |
