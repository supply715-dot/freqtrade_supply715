🧠 봇 자동 로그인 탑재 완료

본 가이드의 실시간 상태 확인용 WebUI(localhost:8080)에는 원클릭 자동 로그인이 내장되어 있습니다. 바탕화면의 실행 바로가기를 더블 클릭하면 자동으로 ID/PW가 입력되어 메인 화면으로 진입합니다.

📈 1. WebUI(FreqUI) 주요 설정 항목의 상세 의미

WebUI의 Configuration 탭 및 제어 화면에서 확인하고 조절할 수 있는 핵심 옵션들의 정량적 의미와 퀀트 설계 의도입니다.

설정 변수명 현재값 상세 의미 및 작동 원리
max_open_trades 2 동시에 가동할 수 있는 최대 포지션 수입니다. 현재 2로 세팅되어 있어 비트코인과 이더리움이 각각 1개씩 포지션을 쥐며 자금을 양분합니다.
stake_amount unlimited 1회 진입 시 베팅할 투자 원금 크기입니다. unlimited로 지정하면, 현재 계좌의 가용 잔고(USDT) 전체를 사용하여 지수함수적 복리(Compounding) 효과를 극대화합니다. (단리로 고정 시 100 등의 고정 액수 기입 가능)
dry_run true 모의 가상 매매 활성화 여부입니다. true이면 실제 돈이 아닌 가상의 1,000 USDT로 실시간 호가창에서 가상 체결을 검증합니다.
margin_mode isolated 선물 마진 모드입니다. isolated(격리 마진)를 사용하여 시장 이상 파동으로 인한 강제 청산 시 전체 지갑 잔고가 아닌 해당 포지션에 들어간 증거금만 잃도록 차단합니다.
stoploss -0.08 절대 최대 손절 폭입니다. 레버리지를 감안하여 기초 자산이 진입가 대비 약 -1% 내외(배율 적용 시 계좌 손실 -8%) 역주행하면 칼같이 스탑로스 시장가 청산이 격발됩니다.
trailing_stop true 트레일링 익절 추적 기능입니다. 가격이 상승하여 익절 목표(+5% 오프셋)에 도달하면, 고점 대비 -2% 하락할 때까지 익절 라인을 위로 끌어올리며 추적하여 최대 수익을 보존합니다.
freqai.enabled true 머신러닝 모듈 활성화 여부입니다. 인공지능이 24시간 동안 실시간으로 다음 봉의 등락 확률(Target ROI)을 회귀 연산하기 위해 필수적으로 활성화되어 있습니다.

⚡ 2. 드라이런(모의)에서 실제 매매(Live Trading)로 전환하는 법

가상 테스트 단계를 끝마치고, 거래소의 실제 자금(USDT)을 사용하여 봇이 실전 자동 양방향 매매를 하도록 스위칭하는 정밀 가이드라인입니다.

1

Bybit 거래소 선물 지갑 및 자산 준비

Bybit 거래소 계정의 Derivatives(선물) 지갑에 실제 투자할 USDT 증거금을 예치합니다.

2

Bybit 선물 포지션 모드 설정 확인 (★필수)

Bybit 거래소의 BTC/USDT 및 ETH/USDT 선물 거래 화면 우측 상단의 톱니바퀴(Settings) ➡️ Position Mode에 진입하여 반드시 One-way Mode (단방향 모드)로 세팅합니다. (Hedge Mode인 경우 API 주문 거부 에러가 발생합니다.)

3

config.json 설정 변경

프로젝트 폴더의 config.json 파일을 텍스트 에디터로 열어 dry_run 값을 false로 수정합니다.

"dry_run": false,
"stake_amount": "unlimited",  // 복리 가동 시 유지, 안전한 첫 가동 시 100 등 고정 금액 지정 가능
4

V8 전략의 실전 연동 실행

바탕화면의 📈 FreqTradeAI 바로가기를 더블 클릭하여 기동합니다. 봇이 Bybit API Key를 정상 검증하여 연동을 시작하고, WebUI 상단의 상태 뱃지가 Live로 초록색 표시되는지 확인합니다.

⚠️ 실전 매매 전환 시 리스크 당부 사항

실전 매매 전환 후 첫 1주일 동안은 봇이 정상적으로 진입 및 손절/익절 주문을 Bybit에 넣는지 텔레그램 알림과 함께 상시 관찰해야 합니다. 시드가 크다면 최초 1~2주간은 "stake_amount": 100 과 같이 소액 단리로 가동해 안전을 확인한 뒤 "unlimited" 복리로 늘리는 것을 권장합니다.

👥 3. FreqUI 화면 제어 팁

🚨 긴급 포지션 강제 청산 (Force Exit)
  • • 대시보드 내 활성 거래 목록(Active Trades)의 Force Exit 버튼을 클릭합니다.
  • • 봇이 즉각 텔레그램 알림과 함께 Bybit 거래소에 시장가 청산 주문을 내어 해당 포지션을 털어냅니다.
🔐 자동 잠금 및 수동 해제 (Locks)
  • • 연이은 손절 등으로 봇이 특정 자산의 추가 진입을 일시 정지시키면 Locking 탭에 기록됩니다.
  • • 장세가 호전되어 강제로 거래를 재개하고 싶다면, 해당 탭 내의 자물쇠 해제(Unlock)를 클릭해 즉시 거래를 복구할 수 있습니다.

❓ 4. 자주 묻는 질문 및 트러블슈팅 (FAQ)

🙋 Q. 차트 데이터는 4시간에 한 번씩만 가져오나요? 전에는 실시간으로 가져온다고 하셨는데요.

아닙니다. 데이터 수집은 5초 간격으로 실시간으로 계속 수행됩니다.

봇은 config.json의 "process_throttle_secs": 5 설정에 따라 5초 주기로 Bybit 거래소에서 최신 호가 및 체결 데이터를 쿼리합니다. 이에 따라 FreqUI 차트에서 보여주는 4시간봉 중 가장 우측의 생성 중인 캔들(마지막 캔들)은 5초마다 Bybit의 실제 시세를 반영하여 실시간으로 위아래로 움직입니다.

'4시간봉(4h)'이란 수집한 데이터를 묶어 전략적 지표를 계산하거나 머신러닝(FreqAI) 모델의 학습 및 추론에 활용하는 시간 프레임(Timeframe) 단위를 지칭할 뿐, 데이터 수집 주기(Refresh Rate)가 4시간이라는 뜻이 아닙니다. 또한 손절(Stoploss), 트레일링 익절, 비상 청산 감시 등 리스크 관리 프로세스는 매 5초 단위의 실시간 시세를 추적하며 작동하므로 안전합니다.

🙋 Q. 차트 화면에서 시간봉(1분, 5분, 1시간 등)을 마음대로 바꿀 수 없나요? 설정이 안 보입니다.

원인: Freqtrade 봇은 메모리 및 Bybit API 호출 한도를 최적화하기 위해, 현재 구동 중인 전략(V8_BTC_ETH_optimized.py)과 FreqAI 설정에서 정의된 메인 시간봉(여기서는 4시간봉(4h))의 데이터만 거래소로부터 실시간으로 다운로드하고 캐싱합니다. FreqUI 차트는 봇이 직접 수집하여 보관하고 있는 데이터만을 API를 통해 전달받아 시각화하므로, 수집하지 않고 있는 다른 시간봉 데이터는 차트에서 보여줄 수 없어서 선택 메뉴가 보이지 않거나 비활성화됩니다.

해결책: 봇이 바라보는 4시간봉의 진입/청산 마커 외에 15분봉, 1시간봉, 1일봉 등 다양한 시간대에서 상세한 기술적 분석을 하려면, Bybit 거래소 웹사이트나 트레이딩뷰(TradingView)를 별도의 브라우저 창으로 띄워서 함께 확인하는 것을 권장합니다. FreqUI 차트는 봇의 동작 상태를 직관적으로 모니터링하는 디버깅용 보조 툴입니다.

🙋 Q. 브라우저 대시보드 화면이 멈추거나 먹통이 될 때는 어떻게 하나요?

원인: 봇 엔진 프로세스가 예기치 않게 종료되었거나, Bybit API 통신 장애 등으로 연결이 끊겼을 때 발생합니다.

해결책: 실행 중인 FreqTradeAI 터미널 창을 닫고, 바탕화면의 FreqTradeAI 바로가기 아이콘을 다시 더블클릭하여 엔진을 재기동해 주십시오.

🙋 Q. 텔레그램 명령어로도 제어가 가능한가요?

네, 가능합니다. 등록된 텔레그램 방에 접속하여 /status, /balance, /profit 등을 입력하시면 언제 어디서나 봇 상태를 조회할 수 있습니다. 비상 상황 시 텔레그램 창에 /forceexit all 또는 /stop을 입력하면 즉시 모든 포지션을 시장가로 정리하고 봇을 일시정지할 수 있습니다.

🙋 Q. 실전 가동 시 투자금 부족(Insufficient Balance) 경고가 뜹니다.

원인: Bybit 선물 지갑에 보유한 USDT 마진 잔액보다 봇의 베팅 설정(레버리지 및 자금 배분 비율)이 크거나, 펀딩비 등의 지출로 잔고가 부족해진 경우입니다.

해결책: Bybit 선물(Derivatives) 지갑에 예치된 USDT 증거금이 충분한지 확인해 주시고, config.json의 stake_amount를 조절해 주십시오.
