# 📈 조나탄 AI 트레이딩: Freqtrade WebUI 한글 사용 설명서

본 설명서는 **SwingTrendRider V5** 및 **FreqAI(LightGBM)** 모델이 탑재된 조나탄 AI 트레이딩 시스템을 웹 브라우저(WebUI) 및 텔레그램을 통해 효율적으로 제어하고 모니터링하기 위한 종합 가이드라인입니다.

## 1. 🌐 WebUI 접속 및 로그인 방법

웹 브라우저를 통해 실시간으로 봇의 작동 상황과 AI 예측 차트를 시각적으로 확인할 수 있습니다.

* **접속 주소**: `http://127.0.0.1:8080` (또는 서버 외부 IP)
* **로그인 정보** (현재 [config.json](file:///c:/Users/7supp/.gemini/antigravity/260509_freqtrade/config.json)에 등록된 정보):
  * **ID (Username)**: `freqtrader`
  * **비밀번호 (Password)**: `password`

---

### 🚨 중요: "사이트에 연결할 수 없음"이 발생할 때!

WebUI는 정적인 웹페이지가 아닙니다. **Freqtrade 봇 프로세스(서버)가 활성화되어 백그라운드 혹은 터미널에서 작동 중일 때만 접속이 가능**합니다. 봇이 꺼져 있다면 포트 `8080`이 닫혀 접속 오류가 납니다.

#### 💡 해결 방법 (봇 기동하기)
터미널(PowerShell 등)에서 아래 명령어를 실행하여 봇을 기동해 주십시오:

```powershell
# FreqAI(LightGBM)와 SwingTrendRiderV5 전략을 기반으로 가상 매매(Dry-run) 시작 및 WebUI 오픈
freqtrade trade --strategy SwingTrendRiderV5_1h4h_20260516 --freqaimodel LightGBMRegressor --config config.json --dry-run
```

* 봇이 실행되면 로그 최하단에 `API Server started...` 메시지가 표시되며, 그 즉시 `http://127.0.0.1:8080`으로 접속하실 수 있습니다.

> 💡 **보안 팁**: 실거래 가동 시에는 [config.json](file:///c:/Users/7supp/.gemini/antigravity/260509_freqtrade/config.json)의 `api_server` 섹션 내 `password`를 안전한 비밀번호로 변경하여 사용하시는 것을 권장합니다.

## 2. 📊 핵심 화면 및 메뉴 가이드

WebUI 화면 왼쪽 또는 하단의 탐색 바를 통해 각 기능을 활용할 수 있습니다.

### ① 대시보드 (Dashboard)
봇의 전체적인 실시간 상태를 한눈에 모니터링하는 메인 화면입니다.
* **현재 상태 (Status)**: 봇이 정상적으로 실행 중인지(`Running`), 정지 상태인지(`Stopped`) 표시합니다.
* **현재 수익률 (Today's Profit)**: 오늘 하루 동안 확정된 누적 수익금 및 수익률을 실시간 차트로 보여줍니다.
* **열린 거래 (Open Trades)**: 현재 진입하여 보유 중인 코인(BTC, ETH 등)의 포지션 수량, 진입 가격, 실시간 미실현 손익(PnL)을 보여줍니다.

### ② 진입 내역 (Trades)
* 현재 보유 중인 포지션의 상세 정보를 확인하고 직접 개입할 수 있는 화면입니다.
* **Force Exit (강제 청산)** 버튼: 시장이 급변하여 AI 신호 전에 수동으로 안전하게 탈출하고 싶을 때 즉시 시장가로 청산하는 버튼입니다.

### ③ 거래 기록 (History)
* 과거에 완료된 모든 매매 기록이 기록되는 장부입니다.
* 진입일시, 청산일시, 진입가, 청산가, 거래량, 그리고 **청산 사유 (Exit Reason)**가 상세히 기록됩니다.
  * `exit_signal`: V5 전략의 1h EMA 역전 신호로 청산됨
  * `stop_loss`: 스탑로스(-8%) 터치로 청산됨
  * `custom_stoploss`: 수익 구간별 본전 보호 스탑로스로 조기 익절됨

### ④ 페어리스트 (Pairlist)
* 현재 전략이 거래 대상으로 감시하고 있는 코인 목록([config.json](file:///c:/Users/7supp/.gemini/antigravity/260509_freqtrade/config.json)의 `pair_whitelist`)을 확인합니다.
* 활성화된 코인의 실시간 시세와 변동률을 리스트 형태로 조회할 수 있습니다.

### ⑤ 자산 현황 (Balance)
* 바이비트(Bybit) 등 연결된 거래소 계정의 전체 자산 상태를 조회합니다.
* 지갑 잔고(Wallet Balance), 증거금 잔고, 미사용 잔고 및 사용 중인 예수금 비율을 시각적 그래프로 제공합니다.

## 3. 🧠 FreqAI 머신러닝 모니터링법

대시보드 상에서 AI 차트를 활성화하면 단순 보조지표가 아닌 **LightGBM이 분석한 데이터**를 볼 수 있습니다.

* **예측 목표 (`&-target_roi`)**: LightGBM이 1시간 봉 단위로 분석하여 "향후 6시간 이내에 발생할 예상 변동률"을 나타냅니다. 이 수치가 진입 장벽(예: `+1.2%` 이상)을 돌파하면 롱(Long) 진입 신호가 활성화됩니다.
* **신뢰도 지표 (`DI_ratio`)**: 현재의 시장 흐름이 머신러닝이 학습한 데이터 범위 내에 있는지 판단하는 지표입니다.
  * `DI_ratio < 0.5`: AI가 현재 시장을 높은 확률로 잘 알고 있으며 신뢰도가 높음 (진입 허용)
  * `DI_ratio >= 0.5`: 시장 변동성이 비정상적이거나 AI가 모르는 구간 (진입 금지/대기)

## 4. ⚙️ 주요 동작 제어 및 꿀팁

### 🔄 자동 새로고침 (Auto Refresh)
* 화면 상단의 **새로고침 아이콘** 옆의 스위치를 켜두면, 5초마다 거래소 잔고와 실시간 미실현 손익 데이터를 백그라운드에서 자동으로 새로고침합니다.

### 🌓 야간 모드 (Theme Toggle)
* 우측 상단의 해/달 모양의 아이콘을 누르면 다크 모드와 라이트 모드로 UI 테마가 즉시 전환되어, 야간 모니터링 시 눈의 피로를 덜 수 있습니다.

## 5. 📱 연동된 텔레그램(Telegram) 원격 제어 가이드

WebUI를 계속 켜두지 않아도 텔레그램을 통해 주머니 속에서 편리하게 전체 시스템을 모니터링 및 수동 제어할 수 있습니다.

### 💬 실시간 주요 알림 형태
1. **포지션 진입 시**: 코인 페어명, 진입 방향(BUY/SELL), 진입가, 레버리지(5x) 정보 자동 전송
2. **포지션 청산 시**: 청산가, 보유 시간, 최종 실현 수익률 및 수익금(USDT) 알림 전송

### ⌨️ 필수 텔레그램 명령어 목록
봇 대화창에 아래 명령어를 입력하여 실시간 정보를 즉시 받아볼 수 있습니다.

| 명령어 | 기능 설명 |
| :--- | :--- |
| `/status` | 현재 보유 중인 포지션의 실시간 미실현 수익률 요약 조회 |
| `/profit` | 시스템 가동 이후 지금까지 누적된 전체 실현 손익 분석 |
| `/balance` | 거래소 내 현재 보유 중인 실제 잔고 현황 조회 |
| `/daily` | 최근 7일간의 일별 수익금 정밀 요약 리포트 전송 |
| `/forceexit <trade_id>` | WebUI에 접속하지 않고도 텔레그램 명령으로 특정 거래 즉시 시장가 강제 종료 |
| `/stop` | 새로운 거래 진입을 일시 중단 (기존 포지션 관리는 유지됨) |
| `/start` | 중단했던 거래 진입을 다시 재개 |

## ⚠️ 모니터링 시 주의사항

1. **레버리지 위험 관리**: 현재 5배 레버리지를 사용하므로, -8% 손절선 터치 시 실자산 대비 약 **-40%**의 손실이 발생할 수 있습니다. WebUI의 손익 변동폭에 일희일비하지 않고 머신러닝과 V5 스탑로스 규칙을 신뢰하는 것이 중요합니다.
2. **API 연결 끊김 감지**: 만약 WebUI 자산 현황 화면에 잔고가 오랫동안 업데이트되지 않거나 오프라인(`Offline`) 빨간 불이 들어온다면, 바이비트 API 키 만료 여부 혹은 인터넷 연결 상태를 점검하십시오.
